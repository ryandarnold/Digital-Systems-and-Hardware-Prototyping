## Projects

### Fitbit Replica 
(Team of 2)

A Fitbit-inspired activity tracking system implemented on an FPGA that simulates step counting, distance tracking, and activity monitoring using modular Verilog design and seven-segment displays.

---

### MIPS CPU
A MIPS processor implemented in Verilog and synthesized on an FPGA, supporting a subset of the MIPS ISA and extended with custom ARM-inspired instructions such as `JAL`, `LUI`, `ADD8`, `RBIT`, `REV`, `SADD`, and `SSUB`.

---

### Stack Calculator
A stack-based calculator implemented using FPGA Block RAM and Verilog control logic, supporting push/pop operations, arithmetic computation, and seven-segment display output.

---

### Systolic Array
(Team of 2) 

A 3×3 matrix multiplication system implemented using a systolic array architecture and multiply-accumulate (MAC) units for pipelined hardware computation.
